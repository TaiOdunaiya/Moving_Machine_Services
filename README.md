# Moving Machine Services Website

A professional website for Moving Machine, a full-service moving company based in Round Rock, Texas. The website showcases the company's services, customer testimonials, and contact information.

## Project Structure

```
├── mm_index.html          # Main homepage
├── mm_services.html       # Services page
├── mm_base.css           # Base styling
├── mm_layout.css         # Layout specific styling
├── Moving_Machine_pic.jpg # Company image
├── Truck_2.jpg           # Moving truck image
└── comments-logo-275-5149.png # Comments section logo
```

## Features

- Clean, professional design
- Customer testimonials section
- Responsive layout
- Contact information with clickable phone and email links
- Service overview
- Custom favicon with gear icon

## Pages

### Home Page (mm_index.html)
- Company overview
- Customer testimonials
- Contact information
- Company images

### Services Page (mm_services.html)
- Detailed service offerings
- Service-specific information

## Maintenance

To update the website:
1. Edit the HTML files for content changes
2. Modify CSS files for styling adjustments
3. Update images as needed in the root directory
4. Ensure all links remain functional
5. Test across different browsers for compatibility.
